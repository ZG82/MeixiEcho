第一章授权音乐接入说明

1. 请确认你拥有《平凡之路》音频用于本项目的合法授权。
2. 将已授权的 mp3、wav 或 ogg 文件重命名为：PingFanZhiLu
3. 放在本目录中，例如：Assets/MeixiEcho/Resources/Audio/PingFanZhiLu.mp3
4. Unity 完成导入后，第一章会自动加载该音源；未检测到文件时会使用项目原创的“梅溪五声音阶·电子山歌”。

程序加载路径：Resources.Load<AudioClip>("Audio/PingFanZhiLu")
授权音乐的节拍基准按 76 BPM 驱动敌人攻击；原创占位音乐按 92 BPM 驱动。
