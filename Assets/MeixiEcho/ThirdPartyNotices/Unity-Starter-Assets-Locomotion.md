# Unity Starter Assets locomotion

The player locomotion controller uses the following Humanoid animation clips
from the Unity Starter Assets third-person character sample supplied with the
local reference project:

- `Stand--Idle.anim.fbx`
- `Locomotion--Walk_N.anim.fbx`
- `Locomotion--Run_N.anim.fbx`
