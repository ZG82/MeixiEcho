ABOUT THE GAME

当村庄逐渐沉默，谁还记得自己的声音？

《梅溪回响》是一款以乡村声音记忆为主题的第三人称剧情动作音游。玩家将跟随电子信息专业学生林默来到闽清梅溪村，在溪流、古桥与旧厝之间探索，通过对话、魂音采集、节拍战斗和机关解谜，让正在消失的乡音重新响起。

“声音怎么可能有记忆？”从采集第一枚破碎音符开始，林默将面对失调的溪灵，也将重新理解技术、音乐与故乡的关系。

实机画面：沿溪流与古桥探索梅溪村

KEY FEATURES

聆听、回应，然后合奏

聆听村庄

沿溪流、民居与古桥收集声音。水滴、竹叶、脚步与乡音，都将成为可演奏的记忆。

节拍战斗

敌人的攻击写在节拍里。近战突进、远程音符与瞬身闪避，需要在魂音收束的瞬间回应。

双手声部

在高强度战斗中同时操控持续声部与主旋律，在混乱的节拍里完成真正的合奏。

乡村叙事

从泛黄日记到村民对话，逐步拼回一座村庄的声音记忆，以及林默与故乡之间被忽略的联系。

实机画面：看清锁定，踩准节拍，回应攻击
