# 《梅溪回响》第三人称 3D Demo

Unity 6000.5.3f1 开发的 Windows 第三人称剧情动作音游竖切版本。

## 当前版本

- 紧凑型 3D 梅溪村地图，可自由探索。
- 第三人称 WASD 移动、鼠标环绕/缩放镜头、跳跃与踏音冲刺。
- 溪流、石桥、古厝、橄榄林、梯田、陶瓷龙窑等乡村场景。
- 三维声纹攻击、节拍增伤、噪音兽战斗、受伤与复活点。
- 五章剧情、打字机对话、章节转场及五组渐进式动作谱面。
- 轻击、蓄力重击、闪避、方向突击、合奏爆发六类节奏动作，不是单一键块玩法。
- 进入魂音时自动聚焦，命中触发近景/侧切，重击与失误触发震屏和视角反馈。
- 原创曲《梅溪五声音阶·电子山歌》，随各章 BPM 同步变速。
- 魂音粒子、攻击波、方向斩、地脉震波、脚步音尘、冲刺流光、乡灯与陶火光效。
- 华丽 HUD、文字描边/阴影/呼吸效果、节奏判定爆字和原创 UI 背景。

## 操作

| 按键 | 操作 |
| --- | --- |
| W / A / S / D | 自由移动 |
| 鼠标 | 环绕第三人称镜头 |
| 滚轮 | 镜头缩放 |
| Space | 跳跃 / 推进对话 |
| Shift / Q | 踏音闪避 |
| J / 鼠标左键 | 轻击 |
| 按住 K / 鼠标右键后松开 | 节奏蓄力重击 |
| A + J / D + J | 左 / 右方向突击 |
| J + K | 合奏爆发 |
| E | 调查魂音 / 推进对话 |
| Esc | 释放或锁定鼠标 |

## Unity 中运行

打开 `Assets/Scenes/SampleScene.unity` 后点击 Play。

## 构建

Unity 菜单选择 `梅溪回响 > 构建 Windows Demo`，输出到：

`Build/Windows/MeixiEcho.exe`

现有 Input System、URP、uGUI 包已经足够，不需要额外安装包。
